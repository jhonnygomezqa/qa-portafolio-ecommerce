# QA Portafolio E-commerce

Proyecto práctico de QA manual sobre una tienda online de prueba
(https://www.saucedemo.com).

## Objetivo
Demostrar el ciclo completo de pruebas manuales: análisis de
requisitos, diseño de casos de prueba, ejecución y reporte de bugs.

## Alcance
- Login
- Catálogo de productos
- Carrito
- Checkout

## Estructura del repositorio
- 01-analisis-requisitos
- 02-casos-de-prueba
- 03-ejecucion-y-bugs
- 04-informe-final

## Estado
En progreso. Autor: Jhonny Gómez Campero, QA Tester Manual (Málaga).
